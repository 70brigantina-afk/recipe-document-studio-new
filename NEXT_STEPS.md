# Продолжение работы над книгой рецептов

Дата фиксации: 24 сентября 2026.

## Адреса

- Рабочий сайт на GitHub Pages: https://70brigantina-afk.github.io/ProjectMind/recipes/
- Исходный код и каталог: https://github.com/70brigantina-afk/recipe-document-studio-new
- Два канала MAX: https://web.max.ru/-72686868718944 и https://web.max.ru/-71971717048987

## Состояние

Сейчас в опубликованной книге 19 рецептов. Есть поиск по названию, ингредиенту и автору, категории и группировка по автору. Проверенные исходные ссылки ведут на отдельный пост, не на канал. В нескольких карточках прямую ссылку ещё нужно установить. История обоих каналов MAX перенесена частично; постоянное отслеживание новых постов не настроено. Добавленные через форму рецепты хранятся локально в браузере и экспортируются в JSON. Импорт по ссылке срабатывает только для сайтов, разрешающих браузерное чтение и предоставляющих структурированные данные о рецепте.

## Следующий этап по желанию Ирины

1. Добавить рецепты из выбранного ею Telegram-канала. Дождаться ссылки на канал.
2. Разделить все рецепты по признаку **«ПП» / «Обычный» / «Не определено»**. Это отдельное поле и фильтр, независимые от категории блюда («Выпечка», «Напитки» и т. д.) и автора. Не помечать весь Telegram-канал как ПП: определять по каждому рецепту отдельно; при сомнении оставлять «Не определено».
3. Сохранять для каждого рецепта конкретную ссылку на публикацию, автора, фото и видео либо ссылку на видео. Проверять дубли по ссылке и содержимому.
4. Продолжить перенос старых рецептов из двух каналов MAX и уточнить прямые ссылки в уже добавленных карточках.
5. Отдельно решить синхронизацию новых постов. Официальный MAX API требует административного доступа бота к каналу; подписка на чужие каналы его не даёт. Не обещать фоновую синхронизацию до появления работающего способа доступа.
6. Позже при необходимости включить GitHub Pages в отдельном репозитории рецептов и перенести адрес с /ProjectMind/recipes/ без потери данных.

Этот файл хранит состояние проекта для продолжения работы независимо от переписки.
