# Книга рецептов Ирины

Самостоятельный каталог на GitHub Pages. Поиск по названию, ингредиенту и автору; фильтры по категориям; прямые ссылки на проверенные исходные посты.

Рецепты в `recipes.json` общие для всех устройств. Добавленные через форму на сайте рецепты остаются в браузере пользователя: их можно выгрузить в JSON и восстановить на другом устройстве. GitHub Pages не предоставляет сервер для сохранения записей или обхода ограничений чтения чужих сайтов. Импорт по ссылке срабатывает для сайтов, которые разрешают браузеру читать страницу и содержат разметку Schema.org Recipe; для остальных потребуется заполнить карточку вручную.

Два канала MAX: `https://web.max.ru/-72686868718944`, `https://web.max.ru/-71971717048987`. Для фонового чтения новых постов через официальный MAX API боту нужны права администратора канала. У каталога таких прав нет, поэтому обещать автоматическую синхронизацию чужих каналов нельзя.

Опубликованные карточки с непроверенными адресами не ведут на главную страницу чата. Кнопка источника появляется только после проверки ссылки на отдельный пост.
